# Zapstore screenshots

The six files here are the listing, in the order `zapstore.yaml` lists them.

| File | Screen | Why it is in |
|---|---|---|
| `01-premise.jpg` | Onboarding, "Bounties for whoever is in range" | States what the app is in one sentence |
| `02-feed.jpg` | Nearby feed with an open bounty | The main screen, with the peer and radio badges visible |
| `03-post.jpg` | Post a bounty, filled in | Shows how a job is created |
| `04-claimed.jpg` | Bounty claimed, waiting on the poster | The claim half of the loop |
| `05-done.jpg` | Bounty paid, with the Witnesses section | Completion, and the witness record |
| `06-mesh.jpg` | Nearby phones, one phone in range | The mesh made visible, with secure and online badges |

Straight off the phone at 1080x2400, no device frames and no marketing text.

Four others were taken and left out: the two remaining onboarding slides, the
Claimed tab (it repeats 05), and Settings. The last two of those also showed a
Nostr public key on screen, which does not belong in a store listing.

To change the set, edit the `images:` list in `zapstore.yaml` to match.
